# 快捷键

## 结构与聚焦

| 按键 | 动作 |
|---|---|
| `Enter` | 在光标处分裂当前节点；节点为空时**在原来那一层**新建一个同级空节点（可连着按、连着建）。**任何层级都一样**，不升不降 —— 要减少缩进用 `Shift+Tab` |
| `Tab` / `Shift+Tab` | 缩进 / 减少缩进（支持多选） |
| `Backspace`（行首） | **待办转为普通节点**（去掉标记，节点保留）；否则与上一节点合并；空节点直接删除 |
| `Delete`（行尾） | 与下一节点合并 |
| `Alt+↑` / `Alt+↓` | 节点上移/下移 |
| `Ctrl+D` | 新建主题副本 |
| `Ctrl+Shift+Backspace` | 快速删除主题 |
| `Alt+→` | **聚焦深入当前节点（Zoom-in）** |
| `Alt+←` | **返回上一级 / 全部节点（Zoom-out）** |
| `↑` / `↓` | 上/下节点；`Shift` 连选 |
| 在**左侧空白处**（圆点左边那条空带）按住左键拖动 | 拉出选框，框到的节点全部选中；在那里单击（不拖动）则清空选中 |
| `←` / `→`（行首/尾） | 跳到上/下一节点 |
| `Shift+Enter` | 进入 / 退出描述备注 |
| `Ctrl+.` / `Alt+.`（中文键盘 `。`） | 折叠 / 展开当前节点 |
| `Ctrl+Shift+.` | 折叠 / 展开**同级**节点 |
| `Alt+Shift+.` 或 `Ctrl+Alt+Shift+.` | 全部折叠 / 全部展开（两者之间切换） |
| `Ctrl+Alt+1/2/3` | 按层级折叠（工具栏"层级"下拉同功能） |
| `Ctrl+/` | 打开 / 关闭快捷键速查面板 |
| `Esc` | 取消多选 / 关闭面板 |

## 待办

| 按键 | 动作 |
|---|---|
| `Ctrl+Shift+L` | 设为待办 |
| `Ctrl+Shift+K` | 设为完成（待办轮转另见工具栏 ☑ 按钮） |
| 行首 `[] ` / `[x] ` + 空格 | 转待办/完成 |

## 插入

| 按键 | 动作 |
|---|---|
| `Alt+Enter` | 添加图片 |
| `Ctrl+Alt+T` | 添加表格 |

## 表格内

| 按键 | 动作 |
|---|---|
| `Tab` | 移到下一个单元格（先表头行，再逐行） |
| `Shift+Tab` | 移到上一个单元格 |

★ `Tab` 在最后一个单元格停住，不会跳出表格：光标一旦跑到正文里，下一次回写就会把它存下来。
其余按键都交给浏览器 —— 单元格里是纯文本，所以输入的 `|` 或 `<` 会被转义存储，而不是被吞掉。

## Markdown 行首 + 空格

`- ` → 去前缀；`1. ` → 编号。
★ `# ` + 空格**不在其中**：它以前会给节点设置标题级别，而那个级别永远读不回来（每个节点都是列表项，
思源只从非列表行取标题级别）。现在它就保留为普通文本 —— 这正是列表项能承载的。文档里已有的标题仍会
被读取并保留。

行内粘贴支持 `**b** *i* ~~s~~ `code` [t](u) $公式$ #标签`（导入 md 时）；
编辑中 `$latex$ + 空格` 自动转公式块。

## 鼠标与交互

- **大纲圆点**：**单击深入聚焦（Zoom-in）**；`Alt+单击` 递归折叠/展开；**双击也聚焦**；拖拽圆点移动（上/中/下三区）。
  再次单击已聚焦的圆点即返回上一级（Zoom-out）。
- **思维导图**：单击节点**选中**该节点并把键盘焦点交给画布（不会切换视图）；**双击节点进入行内编辑**（只读模式下改为聚焦该分支）；右键节点弹出菜单；点击「返回全图」重置。
- **面包屑导航**：顶部点击任意祖先节点可直接跳转对应层级。

## 其他

`Ctrl+Z / Ctrl+Shift+Z / Ctrl+Y` 撤销重做（连续输入 1.2s 内合并一步，且仅限文本编辑；常量见 `src/core/undo-window.ts` 的 `UNDO_MERGE_MS`）；
`Ctrl+F` 查找替换；`Ctrl+B/I/U` 粗斜下划线、`Ctrl+Enter` 删除线。
