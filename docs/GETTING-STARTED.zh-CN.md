# 快速上手

> 这份文档面向**第一次使用**的读者，从安装到上手。
> 想了解「为什么这样设计」，见 [README](../README.zh-CN.md)；
> 想查按键，见 [快捷键](SHORTCUTS.md)。

---

## 这是什么

思源笔记里的**大纲 = 列表块**。这个插件让你用「大纲 / 导图」两种视图
去编辑这些列表块本身 —— 不导出、不镜像、不产生第二份数据。

你在插件里改一个节点，思源文档里的对应列表项就跟着变；反之亦然。

---

## 一、打开插件（桌面端）

插件界面在**右侧栏**，不需要新建标签页。

### 步骤

1. 在右侧栏找到 **导图** 图标（一个「列表 → 分支」的图形）。它通常排在
   侧栏下半部，但**具体位置取决于你装了哪些插件** —— 图标顺序可以在
   `设置 → 外观 → 侧栏` 里自行调整，所以以图形为准、不用记第几个。

   ![右侧栏的导图图标](images/desktop-04-dock-icon.png)

2. 点它，面板就在右侧展开。

   ![打开后的面板](images/desktop-01-outline.png)

3. **面板会自动跟随你当前打开的文档** —— 在左边点开任意一篇含列表的文档，
   面板立刻显示它的大纲。不需要先点面板。

> **看不到图标？** 它可能在右侧栏的折叠区里。把鼠标移到右侧栏底部，
> 会出现一个 9 点图标，点开可展开全部图标。

### 也可以用命令面板

`Alt+Ctrl+P`（macOS 是 `⌥⌘P`）打开命令面板，输入「导图」即可。

插件注册了三个条目，`设置 → 快捷键 → plugin` 里能看到：

| 条目 | 默认键（Win/Linux） | macOS | 作用 |
|---|---|---|---|
| **打开导图** | `Alt+Ctrl+O` | `⌥⌘O` | 新开一个「导图」标签页 |
| **插入镜像块** | `Alt+Ctrl+I` | `⌥⌘I` | 把导图**嵌入文档正文末尾** |
| 打开面板 | （未绑） | | 等同于点右侧栏图标 |

> 思源在 Windows / Linux 上把 `⌘` 显示为 `Ctrl+`、`⌥` 显示为 `Alt+`，
> 所以同一组键在设置里看到的是 `Alt+Ctrl+O` —— 顺序不同，按键是一样的。

> 为什么是 `O` 和 `I`：**这两个键在思源内置里是空的**。
> 插件原先用 `⌥⌘M`，而它早被思源占走（`/editor/insert/memo` 插入备注）——
> 两个命令绑同一个键，按下后谁生效取决于谁先接走事件，等于碰运气。
> 现在改为不与内置键冲突的组合，并由 `src/plugin/hotkey-collision.test.ts`
> 在每次跑测试时核对（对照 `__fixtures__/siyuan-keymap.json` 快照）。

## 二、两种视图

面板顶部有两个切换按钮：**大纲** 和 **导图**。

### 大纲视图

![大纲视图](images/desktop-03-panel-toolbar.png)

和幕布 / Workflowy 类似的大纲编辑器：

- 顶部工具条：待办、日期、H1–H3、正文、粗体、斜体、删除线、行内代码、
  下划线、高亮、引用、链接、公式、图片、表格、表情、标签、双向链接…
- 节点行右侧有折叠箭头
- 拖拽左侧圆点可移动节点（上/中/下三个落点区域）

### 导图视图

![导图视图](images/desktop-02-mindmap.png)

顶部四个下拉框可实时调整外观：

| 控件 | 可选值 |
|---|---|
| **结构** | 向右（默认）、平衡、向左、向下、交替 —— 共五种，在工具栏下拉里切换 |
| **连线** | 平滑曲线、圆角折线、直角折线 |
| **风格** | 彩色、黑白、灰蓝、棕色、绿色、橙色、蓝色、深色（共 8 套） |
| **形状** | 圆角矩形、直角矩形、胶囊形、下划线、六边形、切角矩形、标签形 |

> 上面这些值和插件里看到的**完全一致**，不是示意。</br>

右下角两个浮动按钮：🎨 切换配色、⤢ 适应画布。

## 三、基本操作

下面这些是在**任意一个视图**里都成立的。

### 新建 / 编辑

| 操作 | 怎么做 |
|---|---|
| 新建同级节点 | 光标在节点末尾按 `Enter` |
| 新建子节点 | `Tab` 或在行尾按 `Enter` 后再 `Tab` |
| 编辑文字 | 直接打字 |
| 加备注 | `Shift+Enter` 展开附属段落 |
| 删除节点 | `Ctrl+Shift+Backspace` |

### 移动

| 操作 | 怎么做 |
|---|---|
| 上下移动 | `Alt+↑` / `Alt+↓` |
| 缩进 / 反缩进 | `Tab` / `Shift+Tab` |
| 拖拽移动 | 按住左侧**圆点**拖到目标位置 |

拖拽时圆点周围会出现落点提示：拖到节点**上方**变兄弟、**中间**变子节点、
**下方**变下一个兄弟。

### 折叠

| 操作 | 怎么做 |
|---|---|
| 折叠 / 展开当前节点 | `Alt+单击圆点` |
| 折叠同级 | `Ctrl+Shift+.` |
| 全部折叠 / 展开 | `Alt+Shift+.` |
| 按层级折叠 | `Ctrl+Alt+1/2/3` |

### 聚焦（Zoom）

节点太多时，可以「走进」某一个分支单独编辑：

- **单击圆点** → 以该节点为根显示（面包屑会出现路径）
- 再次单击该圆点，或按 `Alt+←` → 返回上一级

---

### 多选与批量操作

选中 **2 个以上**节点后，上方会出现一条批量工具栏，
可对它们一次性做：缩进 / 减少缩进 / 上移 / 下移 / 设待办 / 完成 /
清待办 / 删除。

| 想做什么 | 怎么做 |
|---|---|
| 加选一个 | `Ctrl`（macOS `⌘`）+ 点击 |
| 选一段连续区间 | 点击起点，再 `Shift` + 点击终点 |
| 连着选多个 | 点第一个，再按 `Shift+↑` / `Shift+↓` |
| 全选 | 工具栏的 `☑` |
| 取消多选 | `Esc`，或直接点别的地方 |

> **单击（不加修饰键）= 编辑这一行**，它会清掉当前的多选。
> 想保留选择请用 `Ctrl+点击`。

#### 概要 和 连接线 已不可用

它们已被移除。思源没有原生方式保存这两样东西：概要（一对大括号）和连接线（两个主题之间的虚线箭头）
都无法在重新打开文档后保留 —— 它们只存在于你关闭文档之前，而工具栏却一直在提供。与其保留一个结果会
消失的按钮，不如把它们从产品中去掉。已有文档仍可正常打开，只是不再显示大括号和箭头。

## 四、移动端

移动端**没有右侧栏**，所以入口和桌面端不一样。

### 步骤

1. 打开任意一篇文档。
2. 点屏幕**最底下**工具栏里的 **更多**（最右边那个 `⋯`）。

   ![移动端界面](images/mobile-01-home.png)

3. 在弹出的菜单里往下找 **插件** 分组，点 **原生大纲导图 - 导图**。

   面板会从右侧滑出，显示当前文档的大纲 —— 和桌面端是同一套界面：

   ![移动端导图面板](images/mobile-02-doc.png)

4. 面板底部是与桌面端一致的工具条，可直接编辑。

> **小技巧**：思源的移动端底栏（导航栏）支持自定义。把这 3 步走一次后，
> 插件图标会出现在「更多」菜单里；如果思源版本支持把插件 dock 固定到底栏，
> 之后就能一键打开，不必每次翻菜单。

> **另一种用法**：在正文里输入 `/` 调出斜杠菜单，选 **插入导图**，
> 会在正文中插入一个**镜像块** —— 导图跟着文档一起滚动，导出时也在。
> 这需要外接键盘（手机上的软键盘一般打不出 `/` 菜单的稳定输入），
> 桌面上用命令面板的 **插入镜像块** 也一样（`Alt+Ctrl+I`，macOS `⌥⌘I`）。

### 触摸手势

| 手势 | 动作 |
|---|---|
| **长按 350ms 后拖动** | 移动节点（触摸设备不触发 HTML5 drag，所以用长按） |
| 点圆点 | 聚焦 / 返回 |
| 双击节点 | 编辑 |

## 五、常见问题

**Q：面板显示「还没打开文档」？**

在左侧点开任意一篇文档即可。面板会自动跟随，不需要手动关联。

如果你点开了文档但面板仍为空，请确认该文档**含有列表块**
（`- 内容` 形式）；纯空文档或只有段落的文档没有大纲可显示。

**Q：新建的文档一直显示「这篇文档还没有内容」，我加了内容它也不变？**

这曾经是个真 bug（v0.1.4 修）。现在：**在正文里加一个列表项，面板会自己跟上**。

注意判据是**列表项**（输入 `- ` 开头，或按工具栏的列表按钮），
不是普通段落 —— 大纲只收列表项，段落不进大纲，这是设计如此。

如果你确实只写了段落而想看大纲：在该段落上按 `Tab`（或加一个列表项），
它就会出现在面板里。也可以直接在**面板里**按 `Enter` 新建第一个节点。

**Q：改了面板里的内容，思源文档没变？**

正常情况下是实时写回的。若出现「保存中…」长时间不消失，
右上角会出现错误提示条，按提示处理。

**Q：能卸载吗？卸载后我的笔记会怎样？**

完全可以。插件**不写入任何自定义属性、不生成私有格式**——
节点就是普通的列表项。卸载后文档照常可读、可搜、可编辑。

**Q：和「导出为图片」有什么区别？**

本插件不导出。你看到的导图是**实时**由列表块渲染出来的；
不存在「导出后原文变了要重新导出」的问题。
