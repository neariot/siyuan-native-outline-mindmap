# 原生大纲导图

[English](README.md) | **简体中文**

用**大纲**和**导图**两种视图编辑思源文档里的列表 —— 数据还是思源那份，
插件只是换了个画法。

## 怎么用

**桌面端**

1. 打开一篇文档（内容最好是列表）。
2. 点右侧栏下半部的**导图图标**，面板就出来了。

   > 图标位置取决于你装了哪些插件，以图形为准，不用记第几个。

3. 面板顶部可在 **大纲 / 导图** 之间切换，中间的工具条直接改内容。

**移动端**

1. 打开文档 → 点底部工具栏最右边的 **更多**（`⋯`）。
2. 在菜单里往下找 **插件** 分组 → 点 **原生大纲导图 - 导图**。

**在正文里嵌入一张图**

在文档中输入 `/` 调出斜杠菜单 → **插入导图**，会在正文插入一个内嵌块，
跟着文档一起滚动、导出时也在。

👉 **[图文上手指南](docs/GETTING-STARTED.md)** —— 完整步骤、界面标注、
快捷键、触摸手势，含截图与操作录屏。

## 功能

- **大纲**：无限层级、Tab 缩进、多选批量、聚焦与面包屑、查找替换
- **导图**：6 结构 × 8 主题 × 3 线型、7 种节点形状、聚焦分支、PNG / Freemind 导出
- **双向实时同步**：思源改 → 视图变；视图改 → 思源变
- **移动端可用**：底部工具栏 → 更多 → 插件
- **安全**：增量写回（绝不整篇替换，避免重建块 ID 摧毁引用 / 反链）、
  删除闸门、防回声、冲突基线与一键恢复

## 实现方式

节点就是思源文档里的**列表块本身**，插件不生成私有副本、不写自定义属性、
不做格式转换。因此：

| 检验项 | 结果 |
|---|---|
| 文档块属性（`attributes` 表） | **0 条** |
| 卸载插件后打开文档 | 就是**普通列表**，照常可编辑 |
| 全文搜索导图节点 | **搜得到**（节点是正文） |
| 在思源里改块、再开导图 | **自动同步**（无缓存） |
| 任务 / 标题 / 备注 | 全部是思源**原生**任务列表 / H1–H6 / 附属段落 |

与「导出成图片 / 私有格式」的做法相比，好处是图上内容**搜得到**、
不做第二份数据、卸载后文档仍可读。这些可以自行验证：
建一篇文档，改几个节点，再查 `attributes` 表即可。

## 界面语言

界面文案已全部接入 i18n，随思源的语言设置切换：

| 思源语言 | 界面 |
|---|---|
| 简体中文 | 中文 |
| English | English |
| 其他 | 回退到英文 |

词条在 `src/plugin/i18n/`（`zh_CN.json` / `en_US.json`，两者必须都有）。

## 构建

```bash
npm install
TARGET=plugin npm run build   # 产物 → dist-plugin/
```

开发预览（独立的 Web 调试外壳，非插件运行环境）：

```bash
npm run dev                   # :8901
```

技术栈：React 18 + Rsbuild + TypeScript + KaTeX。

## 目录

```
src/
├── core/       blockdom.ts   节点树 → 思源 DOM（写入路径）
│               map.ts        节点树 ⇄ 思源 Kramdown（读取路径，纯逻辑零依赖）
│               layout.ts     导图布局
├── model/      types.ts      节点模型
│               tree.ts       增删改查 / 折叠 / 统计
│               ids.ts        思源风格块 ID 生成
├── mindmap/    Mindmap.tsx   SVG 导图
├── plugin/     index.ts      插件入口（注册标签页 / Dock / 斜杠菜单）
│               mount.ts      挂载与写回编排（增量同步、冲突检测）
│               sync.ts       回声守卫 / 冲突追踪 / 差异提取
│               tree-ops.ts   节点操作
│               outline/      大纲视图
├── siyuan/     api.ts        内核 API 客户端
│               store.ts      文档读写（增量写回、块映射、附属段落）
└── types/      siyuan.d.ts   `siyuan` 模块的类型声明
```
