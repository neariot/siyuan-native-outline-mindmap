# Chinese fixture text is a **function label**: it names what a thing is —— a node, the second
# paragraph, a bold run —— and never what it says. A label built only from these words is obviously
# synthetic on sight and cannot have been copied out of a document, because it has no content to copy.
#
# ★ The direction matters. A fixture that does not fit is **renamed to fit**; the vocabulary is not
#  extended to make a fixture pass. Adding a word here to silence a finding turns this file into a
#  description of whatever the tests happen to say, which is the same as having no rule at all
#  (`AGENTS.md` section 2: "the fix is `t('<key>')`, never an exemption").
#
# So a label may contain exactly two kinds of word:
#  1. a *noun for a thing* the plugin deals with —— 节点, 段落, 标题, 列表项, 备注, 图片 …
#  2. a *role or a number* that tells one such thing from another —— 子, 根, 同级, 空, 第二, 一 …
# What it may not contain is a verb, a sentence, or a noun from somebody's subject matter
# —— a label like that is describing content, which is the thing to fix.
#
# Exempt elsewhere, each by a stated rule, in scripts/check-fixture-text.py: catalogue values, semantics
# (full-width punctuation, U+3000, zero-width characters, outside the BMP, CJK/ASCII mixes), the
# language allowlist, and one-character labels —— which describe nothing and cannot carry content.
#
# One entry per line. A token nothing uses is a finding, the same as in language-allowlist.txt.
